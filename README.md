# Aurea - Production Capacity Assessment

## Project Overview

This project aims to help **Aurea assess and forecast the production capacity of its clients** using reliable, structured, and automated data.

The project covers the full data workflow, from auditing and cleaning the existing data to modelling, forecasting, and pipeline monitoring.

## My Role

My work on the project includes:

- **Database audit & data quality assessment**
  - Review the existing database structure
  - Identify data quality and consistency issues
  - Assess data completeness and reliability

- **Data modelling & table creation**
  - Design and implement the data model
  - Create structured and reliable tables
  - Define unique keys and relationships
  - Clean, standardise, and validate data

- **Production capacity forecasting**
  - Analyse historical production data
  - Identify relevant trends and patterns
  - Build forecasts to estimate production capacity

- **Git workflow & orchestration**
  - Structure and version-control the project using Git
  - Automate data workflows and pipeline execution
  - Implement monitoring and alerting for pipeline or data-quality issues

## Business Objective

The final solution is intended to provide Aurea with a **reliable and reproducible data pipeline** that can support the assessment of current production capacity and help anticipate future capacity.

## Technical Approach

The project will demonstrate the complete data lifecycle:

**Raw data → Data quality & cleaning → Data modelling → Analytics → Forecasting → Orchestration → Monitoring & Alerting**
